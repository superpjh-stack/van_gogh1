# 별이 흐르는 밤

`index.html`을 브라우저에서 열면 설치 없이 실행됩니다.

서버 사용: 이 폴더에서 `node server.mjs` 실행 후 http://localhost:8766 접속.

마우스·터치로 붓결에 반응을 주고, 클릭 또는 작품에 초점을 맞춘 뒤 Enter로 별빛을 만듭니다. 고요/흐름/격정, 정지, 합성 화음과 음량, 전체 화면을 지원합니다. 기기의 동작 줄이기 설정에서는 정지 상태로 시작합니다. 탭을 숨기면 렌더링과 소리가 중지되며 소리는 직접 다시 켜야 합니다.

제공된 512×512 상품 사진의 상단 하늘 영역을 확대합니다. 원본은 상위 폴더에 보존됩니다. 소스 해상도 때문에 큰 화면에서는 붓결이 부드럽게 보일 수 있습니다. WebGL을 지원하지 않는 브라우저에서는 정적인 그림과 별빛 오버레이로 대체합니다.

외부 서비스·API 키·설치 의존성이 없습니다. 이미지 데이터는 파일 직접 실행을 지원하기 위해 image-data.js에도 포함됩니다.

검증: `node --test tests/interaction.test.cjs` — 입력 중복 방지, 효과 상한/수명, 키보드, 모드 선택, 동작 줄이기, 탭 숨김 정리의 7개 모의 상태 검사를 통과했습니다. JavaScript 문법 검사도 통과했습니다. 실행 환경의 포트 열기 제한(EPERM)과 브라우저 file URL 정책으로 실제 브라우저·모바일·음질 검증은 수행하지 못했습니다.

배경음악: 음악 켜기 버튼으로 시작하는 64 BPM 합성 앰비언트 곡입니다. 네 가지 화음, 반복 멜로디, 분산화음으로 구성되며 음량 조절과 끄기를 지원합니다. 탭을 숨기면 음악 예약 타이머와 오디오 컨텍스트를 정리합니다. 우측 하단 서명: made by Gerardo, 2026-10-13.
